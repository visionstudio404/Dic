# 🚀 Quick Start Guide - Task Master

## For Windows Users (You!)

### Step 1: Copy to Your Computer
Copy the entire `task-master` folder from this repository to your Windows computer.

### Step 2: Open Command Prompt
1. Navigate to the `task-master` folder
2. Right-click in the folder
3. Select "Open in Terminal" or "Open Command Prompt here"

### Step 3: Install & Build
Run these commands one by one:

```bash
# Install basic dependencies
npm install --save-dev electron electron-builder

# Build the Windows installer
npm run build
```

Wait 5-10 minutes for the build to complete.

### Step 4: Install Your App
1. Go to the `dist` folder that was created
2. Find `Task Master Setup x.x.x.exe`
3. **Double-click** it
4. Follow the installation wizard
5. Click "Finish"

### Step 5: Use Your App!
- **Desktop shortcut** appears automatically
- **Double-click** to open anytime
- See your tasks, calendar, and notifications
- All data saved locally (offline!)

## Need Help?

### App won't start?
```bash
# Delete and reinstall
rmdir /s node_modules
npm install --save-dev electron electron-builder
npm run build
```

### Can't find npm?
Download Node.js from: https://nodejs.org

### Build fails?
Run Command Prompt as Administrator

### Lost your data?
Find it here: `%APPDATA%\task-master\task-data.json`
