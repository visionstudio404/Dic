## 🚀 How to Get Started


## 🔧 Technical Details

### Technology Stack:
- **Framework**: Electron v30
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js (Electron main process)
- **Storage**: Local JSON file
- **Build Tool**: electron-builder
- **Notifications**: Electron Notification API
- **System Tray**: Electron Tray API

### System Requirements:

**For Building:**
- Windows 10/11
- Node.js v16+ (download from nodejs.org)
- 500MB free disk space
- Internet connection (for initial download)

**For Running (after build):**
- Windows 10/11
- 150MB disk space
- No Node.js required
- Works completely offline

### Installation Output:
After building, you get:
- `dist/Task Master Setup x.x.x.exe` (~150MB)
- Professional Windows installer
- Creates desktop shortcut
- Adds to Start Menu
- Uninstaller included

## 🆘 Troubleshooting

### Common Issues:

**"npm is not recognized"**
→ Install Node.js from https://nodejs.org

**Build fails with permission error**
→ Run Command Prompt as Administrator

**App won't start after install**
→ Check Windows Defender, allow the app

**No notifications showing**
→ Check Windows notification settings
→ Enable notifications in Windows Settings

**Lost my data**
→ Find at: `%APPDATA%\task-master\task-data.json`
→ Copy this file to backup

**Icon not showing**
→ App works without custom icon
→ For production, add icon.png to assets/

**Build takes too long**
→ Normal first time (downloads Electron ~300MB)
→ Subsequent builds are faster
